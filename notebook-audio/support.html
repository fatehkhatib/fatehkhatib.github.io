Common questions

How do I add audio?

Download the audio file — for audio overviews, use the website in Safari, since some apps only save downloads inside themselves — then open it in the Files app, tap Share and choose Notebook Audio. If it isn’t in the row of apps, scroll to the end and tap More. You can also use Library → + → Import from Files.

I shared a link and it says “This is a link”.

Links to web pages that need a sign-in can’t be saved directly. Download the audio file first, then share the file.

Where are my files backed up?

In iCloud Drive → Notebook Audio, with one folder per category. Check backup status in the app’s Settings.

A finished audio shows “In iCloud”.

To save space, finished audio is removed from your iPhone after it’s safely backed up. Tap it to download and play it again. You can change or turn this off in Settings → Free Up Space.

How do I move my library to a new iPhone?

Sign in to the same iCloud account, open the app, then go to Settings → Restore from iCloud.
